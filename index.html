What This Handbook Is

This is an operational delivery handbook — not a blog, not theory. Every page is designed to guide you through real enterprise detection engineering projects from start to finish without additional research, guessing, or hallucinations.

⚠️ Client Reality Check

This handbook is tailored for a Sobeys-scale Canadian grocery & retail enterprise that:

  • Is NOT currently using Risk-Based Alerting (RBA)
  • Has an immature security team not ready for RBA adoption
  • Needs to focus on log coverage and ingestion first
  • Uses Entra ID enterprise-wide with potential multi-provider MFA
  • Has Akamai WAF logs in scope

Core Delivery Principles

Phase 1 First
Log Coverage is the Gate
No detections until Phase 1 is complete. Missing logs = blind spots = failed detections.
Required
Single Environment Testing
No DEV/UAT. All testing uses backtesting → monitoring-only → production enablement.
Future
RBA is Out of Scope
Risk-Based Alerting is a future maturity step. All detections use classic ES notables.

Project Phase Sequence

All projects must follow this sequence. Phase 1 is a hard gate.

Phase 1 Log Coverage & Ingestion Readiness All required logs identified, onboarded, validated
Phase 2 Data Quality & Normalization Field completeness verified, timestamps correct
Phase 3 Detection Engineering Detections backtested, monitoring-only validated
Phase 4 Automation (Optional) Ticketing, enrichment configured
Phase 5 RBA (Future Only) NOT in current scope

How to Use This Handbook

  1. Start with Planning

    Go to Planning & Project Intake to define scope, stakeholders, and acceptance criteria.

  2. Complete Phase 1 (Mandatory)

    Use Log Coverage & Readiness to identify and onboard all required logs.

  3. Follow the Onboarding Guides

    Select the appropriate Primary or Alternate onboarding path for each log source.

  4. Validate Data Quality

    Use Phase 2 checks before building detections.

  5. Build Detections

    Follow Phase 3 for classic ES correlation searches with the monitoring-only lifecycle.

Supported Projects

🛡️ Akamai WAF / DDoS
Application-layer protection with WAF log analysis for bot abuse, credential stuffing, and DDoS detection.
🔐 MFA & Authentication
Multi-provider authentication monitoring with Entra ID and CyberArk Mobile support.
📊 Generic Log Onboarding
Universal framework for onboarding any enterprise log source to Splunk Cloud.

Primary Risks (Retail Context)

🎯 Key Threat Scenarios
  • Application-layer DDoS — Traffic spikes during promotions mask attacks
  • Bot abuse & credential stuffing — Automated attacks on loyalty accounts
  • MFA fatigue — Push notification bombing
  • Account takeover — Customer and employee account compromise
  • Availability impact — False positives during peak hours are high risk

Phase Timeline Reference

Typical duration for each phase in a solo delivery engagement:

Phase Focus Duration Dependencies
P1 Log Coverage Data onboarding, ingestion validation 2-4 weeks Source system access
P2 Data Quality CIM mapping, data model acceleration 1-2 weeks P1 complete
P3 Detection Correlation searches, notable events 2-4 weeks P2 complete
P4 Automation Enrichment, ticketing, SOAR (optional) 1-2 weeks P3 complete
P5 RBA Risk-based alerting (future) 12-18 months Organizational maturity

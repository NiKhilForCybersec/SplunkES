☁️ Splunk Cloud Safety Box — Infrastructure & Decision Guides

✅ Allowed in Cloud: Decision frameworks and evaluation criteria on this page apply to Cloud. HEC is the primary Cloud ingestion path.

⚠️ Restricted in Cloud: Architecture patterns that assume direct indexer access, deployment server management, or filesystem-level configuration apply only to customer-managed infrastructure (HFs, UFs, standalone instances).

🔄 Cloud-Safe Alternative: When this page discusses ingestion architectures, the Cloud path is: external collector → HEC, or UF/HF → Cloud indexing tier. See the Cloud + ES: What's Different page for the full Cloud architecture reference.

🚨 MANDATORY: Follow Source-Specific Guides

This page is an overview only. Each data source has unique requirements, failure modes, and rollback procedures. Always read the source-specific guide BEFORE starting onboarding.

⚠️ Onboarding Priority Order

For detection engineering projects, onboard sources in this order:

  1. Authentication/MFA — Foundation for identity-based detections
  2. WAF/DDoS — Web attack visibility
  3. Endpoint telemetry — Process and file activity
  4. Network devices — Traffic and firewall logs

This order ensures each phase has the data it needs.

Common Configuration Files

Heavy Forwarder: inputs.conf (Syslog)

inputs.conf 
# UDP Syslog - Standard
[udp://514]
sourcetype = syslog
index = prod_network_syslog
connection_host = dns
no_priority_stripping = true

# TCP Syslog - Reliable delivery
[tcp://1514]
sourcetype = syslog
index = prod_network_syslog
connection_host = dns

# TLS Syslog - Encrypted
[tcp-ssl://6514]
sourcetype = syslog
index = prod_security_syslog
connection_host = dns
serverCert = /opt/splunk/etc/auth/server.pem
sslPassword = <encrypted>

Heavy Forwarder: outputs.conf

outputs.conf 
[tcpout]
defaultGroup = splunk_cloud

[tcpout:splunk_cloud]
server = inputs.<stack>.splunkcloud.com:9997
sslCertPath = /opt/splunk/etc/auth/splunkcloud/cert.pem
sslRootCAPath = /opt/splunk/etc/auth/splunkcloud/cacert.pem
sslPassword = <encrypted>
sslVerifyServerCert = true

Troubleshooting Quick Reference

Symptom Likely Cause Check First
No events arriving Network/firewall issue tcpdump -i any port 514
Events delayed Queue backup on HF splunk list inputstatus
Wrong sourcetype Transforms not applied Check props.conf/transforms.conf
Timestamp wrong TIME_FORMAT mismatch Test with | makeresults | eval _raw=...
Events merged LINE_BREAKER issue Check SHOULD_LINEMERGE setting

Scripted Inputs

Custom scripts and API polling for data sources without native Splunk integration

📋 Page Status: HARDENED

Last Audit: 2024-02 | Auditor: Detection Engineering Team

This page includes custom script security requirements, checkpoint management, and rollback procedures.

🚨 CRITICAL: Scripted Inputs Require Custom Code Maintenance

Scripts are custom code that YOU must maintain. Before implementing:

  • Document ownership: Who maintains this script when it breaks?
  • Credential security: NEVER hardcode credentials in scripts
  • Error handling: Scripts MUST handle API failures gracefully
  • Checkpoint required: Without checkpointing, you WILL get duplicates or gaps
⚠️ API Rate Limiting Considerations

Most APIs have rate limits that can cause data gaps:

  • Microsoft Graph: ~10,000 requests per 10 minutes
  • AWS APIs: Varies by service, often 1-10 requests/second
  • Custom APIs: Check vendor documentation for limits

Design scripts to respect rate limits and implement backoff logic.

Architecture Overview

Scripted inputs execute custom scripts on a schedule to collect data from APIs, files, or other sources. Use scripted inputs when no Splunk add-on exists, when you need custom data transformation, or when integrating with proprietary systems. Scripts output data to stdout, which Splunk indexes.

When to Use Scripted Inputs

Scripted inputs are ideal for: APIs without native Splunk add-ons, proprietary vendor systems, custom file formats, command-line tool output, and data requiring complex transformation before indexing. For standard APIs, always check Splunkbase for existing add-ons first.

Prerequisites

Component Requirement Notes
Script Runtime Python 3.9+, Bash, or PowerShell Python preferred for API integrations
Splunk Add-on Builder Optional: for packaging scripts as apps Recommended for production deployments
API Credentials Service account or API keys Store securely in passwords.conf
Network Access Outbound access to API endpoints HTTPS (443) or custom ports
Checkpoint Storage Writable directory for state files Prevents duplicate data on restart

Script Development Principles

Critical Requirements

All scripted inputs must: output to stdout (not files), handle errors gracefully, implement checkpointing for incremental collection, respect API rate limits, and never store credentials in script files.

Script Requirements Checklist

Requirement Description Impact if Missing
stdout Output All data written to stdout Data not indexed
Checkpointing Track last processed timestamp/ID Duplicate events on restart
Error Handling Catch exceptions, log to stderr Silent failures, data gaps
Rate Limiting Respect API throttling API blocks, data gaps
Timeout Handling Set connection/read timeouts Script hangs, queue buildup
Exit Codes Return 0 on success, non-zero on failure Can't monitor script health

Python REST API Script

bin/custom_api_input.py 
#!/usr/bin/env python3
"""
Custom API Input Script
Collects security events from REST API with checkpoint support
"""

import sys
import os
import json
import time
import logging
from datetime import datetime, timedelta

# Add lib directory to path
sys.path.insert(0, os.path.join(os.path.dirname(__file__), 'lib'))

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# Configuration
CHECKPOINT_DIR = os.environ.get('SPLUNK_HOME', '/opt/splunk') + '/var/lib/splunk/modinputs/custom_api'
CHECKPOINT_FILE = os.path.join(CHECKPOINT_DIR, 'checkpoint.json')
API_BASE_URL = os.environ.get('API_BASE_URL', 'https://api.vendor.com/v1')
API_KEY = os.environ.get('API_KEY', '')
PAGE_SIZE = 100
MAX_PAGES = 50
REQUEST_TIMEOUT = 30

# Logging setup - stderr for logs, stdout for events
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s %(levelname)s %(message)s',
    stream=sys.stderr
)
logger = logging.getLogger(__name__)


def get_session():
    """Create requests session with retry logic"""
    session = requests.Session()
    
    # Retry strategy for transient errors
    retry_strategy = Retry(
        total=3,
        backoff_factor=1,
        status_forcelist=[429, 500, 502, 503, 504],
        allowed_methods=["GET", "POST"]
    )
    
    adapter = HTTPAdapter(max_retries=retry_strategy)
    session.mount("http://", adapter)
    session.mount("https://", adapter)
    
    # Set default headers
    session.headers.update({
        'Authorization': f'Bearer {API_KEY}',
        'Content-Type': 'application/json',
        'Accept': 'application/json'
    })
    
    return session


def load_checkpoint():
    """Load checkpoint from file"""
    try:
        if os.path.exists(CHECKPOINT_FILE):
            with open(CHECKPOINT_FILE, 'r') as f:
                return json.load(f)
    except Exception as e:
        logger.warning(f"Failed to load checkpoint: {e}")
    
    # Default: start from 24 hours ago
    return {
        'last_timestamp': (datetime.utcnow() - timedelta(hours=24)).isoformat() + 'Z',
        'last_id': None
    }


def save_checkpoint(checkpoint):
    """Save checkpoint to file"""
    try:
        os.makedirs(CHECKPOINT_DIR, exist_ok=True)
        with open(CHECKPOINT_FILE, 'w') as f:
            json.dump(checkpoint, f)
    except Exception as e:
        logger.error(f"Failed to save checkpoint: {e}")


def fetch_events(session, since_timestamp, cursor=None):
    """Fetch events from API with pagination"""
    params = {
        'since': since_timestamp,
        'limit': PAGE_SIZE,
        'sort': 'timestamp:asc'
    }
    
    if cursor:
        params['cursor'] = cursor
    
    try:
        response = session.get(
            f'{API_BASE_URL}/events',
            params=params,
            timeout=REQUEST_TIMEOUT
        )
        response.raise_for_status()
        return response.json()
    
    except requests.exceptions.Timeout:
        logger.error("API request timed out")
        raise
    except requests.exceptions.HTTPError as e:
        if e.response.status_code == 429:
            # Rate limited - wait and retry
            retry_after = int(e.response.headers.get('Retry-After', 60))
            logger.warning(f"Rate limited, waiting {retry_after} seconds")
            time.sleep(retry_after)
            return fetch_events(session, since_timestamp, cursor)
        raise
    except Exception as e:
        logger.error(f"API request failed: {e}")
        raise


def format_event(event):
    """Format event for Splunk ingestion"""
    # Output as JSON with timestamp
    output = {
        'timestamp': event.get('timestamp'),
        'event_type': event.get('type'),
        'severity': event.get('severity'),
        'user': event.get('user', {}).get('email'),
        'src_ip': event.get('source_ip'),
        'action': event.get('action'),
        'resource': event.get('resource'),
        'result': event.get('result'),
        'message': event.get('message'),
        'raw': event  # Include full event for reference
    }
    return json.dumps(output)


def main():
    """Main collection loop"""
    logger.info("Starting custom API input collection")
    
    # Validate configuration
    if not API_KEY:
        logger.error("API_KEY environment variable not set")
        sys.exit(1)
    
    session = get_session()
    checkpoint = load_checkpoint()
    
    since_timestamp = checkpoint['last_timestamp']
    cursor = None
    total_events = 0
    latest_timestamp = since_timestamp
    
    try:
        for page in range(MAX_PAGES):
            logger.info(f"Fetching page {page + 1}, since={since_timestamp}")
            
            data = fetch_events(session, since_timestamp, cursor)
            events = data.get('events', [])
            
            if not events:
                logger.info("No more events to process")
                break
            
            for event in events:
                # Output event to stdout for Splunk indexing
                print(format_event(event))
                total_events += 1
                
                # Track latest timestamp
                event_timestamp = event.get('timestamp')
                if event_timestamp and event_timestamp > latest_timestamp:
                    latest_timestamp = event_timestamp
            
            # Check for next page
            cursor = data.get('next_cursor')
            if not cursor:
                break
            
            # Rate limit between pages
            time.sleep(0.5)
        
        # Update checkpoint
        checkpoint['last_timestamp'] = latest_timestamp
        save_checkpoint(checkpoint)
        
        logger.info(f"Collection complete: {total_events} events processed")
        sys.exit(0)
        
    except Exception as e:
        logger.error(f"Collection failed: {e}")
        sys.exit(1)


if __name__ == '__main__':
    main()

#!/bin/bash
#
# System Inventory Collection Script
# Outputs JSON for Splunk indexing
#

set -e

# Get system information
HOSTNAME=$(hostname -f)
TIMESTAMP=$(date -u +"%Y-%m-%dT%H:%M:%SZ")
UPTIME=$(uptime -s 2>/dev/null || echo "unknown")
KERNEL=$(uname -r)
OS_VERSION=$(cat /etc/os-release 2>/dev/null | grep "VERSION_ID" | cut -d= -f2 | tr -d '"')

# Get CPU info
CPU_COUNT=$(nproc)
CPU_MODEL=$(grep "model name" /proc/cpuinfo | head -1 | cut -d: -f2 | xargs)

# Get memory info (in MB)
TOTAL_MEM=$(free -m | awk '/Mem:/ {print $2}')
USED_MEM=$(free -m | awk '/Mem:/ {print $3}')
FREE_MEM=$(free -m | awk '/Mem:/ {print $4}')

# Get disk info
DISK_USAGE=$(df -h / | awk 'NR==2 {print $5}' | tr -d '%')

# Get network interfaces
INTERFACES=$(ip -j addr show 2>/dev/null | jq -c '[.[] | {name: .ifname, addresses: [.addr_info[]? | select(.family=="inet") | .local]}]' 2>/dev/null || echo "[]")

# Get listening ports
LISTENING_PORTS=$(ss -tlnp 2>/dev/null | awk 'NR>1 {print $4}' | cut -d: -f2 | sort -u | tr '\n' ',' | sed 's/,$//')

# Get installed security packages
SECURITY_PACKAGES=""
if command -v dpkg &>/dev/null; then
    SECURITY_PACKAGES=$(dpkg -l | grep -E "(crowdstrike|falcon|defender|eset|symantec)" | awk '{print $2}' | tr '\n' ',' | sed 's/,$//')
elif command -v rpm &>/dev/null; then
    SECURITY_PACKAGES=$(rpm -qa | grep -E "(crowdstrike|falcon|defender|eset|symantec)" | tr '\n' ',' | sed 's/,$//')
fi

# Output JSON to stdout
cat << EOF
{
    "timestamp": "${TIMESTAMP}",
    "event_type": "system_inventory",
    "host": "${HOSTNAME}",
    "kernel": "${KERNEL}",
    "os_version": "${OS_VERSION}",
    "uptime_since": "${UPTIME}",
    "cpu": {
        "count": ${CPU_COUNT},
        "model": "${CPU_MODEL}"
    },
    "memory_mb": {
        "total": ${TOTAL_MEM},
        "used": ${USED_MEM},
        "free": ${FREE_MEM}
    },
    "disk_usage_percent": ${DISK_USAGE},
    "network_interfaces": ${INTERFACES},
    "listening_ports": "${LISTENING_PORTS}",
    "security_packages": "${SECURITY_PACKAGES}"
}
EOF

exit 0

#Requires -Version 5.1
<#
.SYNOPSIS
    Collects Windows Security Events for Splunk
.DESCRIPTION
    Reads Security event log with checkpoint support
#>

param(
    [int]$MaxEvents = 1000,
    [string]$CheckpointPath = "$env:SPLUNK_HOME\var\lib\splunk\modinputs\win_security\checkpoint.txt"
)

$ErrorActionPreference = "Stop"

# Ensure checkpoint directory exists
$CheckpointDir = Split-Path $CheckpointPath -Parent
if (-not (Test-Path $CheckpointDir)) {
    New-Item -ItemType Directory -Path $CheckpointDir -Force | Out-Null
}

# Load checkpoint (last processed RecordId)
$LastRecordId = 0
if (Test-Path $CheckpointPath) {
    $LastRecordId = [int64](Get-Content $CheckpointPath)
}

# Event IDs to collect (security-relevant)
$SecurityEventIds = @(
    4624,  # Successful logon
    4625,  # Failed logon
    4648,  # Explicit credential logon
    4672,  # Special privileges assigned
    4720,  # User account created
    4722,  # User account enabled
    4724,  # Password reset attempt
    4728,  # Member added to security-enabled global group
    4732,  # Member added to security-enabled local group
    4756,  # Member added to security-enabled universal group
    4768,  # Kerberos TGT requested
    4769,  # Kerberos service ticket requested
    4776,  # NTLM authentication
    7045   # Service installed
)

try {
    # Query Security event log
    $FilterXml = @"

    
        
    

"@

    $Events = Get-WinEvent -FilterXml $FilterXml -MaxEvents $MaxEvents -ErrorAction SilentlyContinue

    if ($Events) {
        $NewMaxRecordId = $LastRecordId
        
        foreach ($Event in $Events | Sort-Object RecordId) {
            # Parse event to JSON
            $EventData = @{
                timestamp = $Event.TimeCreated.ToUniversalTime().ToString("yyyy-MM-ddTHH:mm:ssZ")
                event_id = $Event.Id
                record_id = $Event.RecordId
                level = $Event.LevelDisplayName
                provider = $Event.ProviderName
                computer = $Event.MachineName
                user_sid = $Event.UserId.Value
                message = $Event.Message -replace "`r`n", " " -replace "`n", " "
            }
            
            # Extract key fields from XML
            $XmlData = [xml]$Event.ToXml()
            $EventXmlData = $XmlData.Event.EventData.Data
            
            if ($EventXmlData) {
                foreach ($Data in $EventXmlData) {
                    if ($Data.Name -and $Data.'#text') {
                        $EventData[$Data.Name] = $Data.'#text'
                    }
                }
            }
            
            # Output JSON to stdout
            $EventData | ConvertTo-Json -Compress
            
            # Track max record ID
            if ($Event.RecordId -gt $NewMaxRecordId) {
                $NewMaxRecordId = $Event.RecordId
            }
        }
        
        # Save checkpoint
        $NewMaxRecordId | Out-File -FilePath $CheckpointPath -NoNewline
        
        Write-Host "Processed $($Events.Count) events" -ForegroundColor Green
    }
    else {
        Write-Host "No new events found" -ForegroundColor Yellow
    }
    
    exit 0
}
catch {
    Write-Error "Collection failed: $_"
    exit 1
}

Checkpoint Management

Checkpointing prevents duplicate data and enables incremental collection across script restarts.

lib/checkpoint.py 
"""
Checkpoint management utilities for scripted inputs
"""

import os
import json
import logging
from datetime import datetime, timedelta
from typing import Optional, Any, Dict

logger = logging.getLogger(__name__)


class Checkpoint:
    """Manages checkpoint state for incremental collection"""
    
    def __init__(self, checkpoint_dir: str, input_name: str):
        self.checkpoint_dir = checkpoint_dir
        self.input_name = input_name
        self.filepath = os.path.join(checkpoint_dir, f'{input_name}.json')
        self._state: Dict[str, Any] = {}
        self._load()
    
    def _load(self) -> None:
        """Load checkpoint from file"""
        try:
            os.makedirs(self.checkpoint_dir, exist_ok=True)
            if os.path.exists(self.filepath):
                with open(self.filepath, 'r') as f:
                    self._state = json.load(f)
                logger.info(f"Loaded checkpoint: {self._state}")
        except Exception as e:
            logger.warning(f"Failed to load checkpoint: {e}")
            self._state = {}
    
    def save(self) -> None:
        """Save checkpoint to file"""
        try:
            self._state['_updated'] = datetime.utcnow().isoformat() + 'Z'
            with open(self.filepath, 'w') as f:
                json.dump(self._state, f, indent=2)
            logger.info(f"Saved checkpoint: {self._state}")
        except Exception as e:
            logger.error(f"Failed to save checkpoint: {e}")
            raise
    
    def get(self, key: str, default: Any = None) -> Any:
        """Get checkpoint value"""
        return self._state.get(key, default)
    
    def set(self, key: str, value: Any) -> None:
        """Set checkpoint value"""
        self._state[key] = value
    
    def get_timestamp(self, key: str = 'last_timestamp', 
                      default_hours_ago: int = 24) -> str:
        """Get timestamp checkpoint with sensible default"""
        timestamp = self.get(key)
        if not timestamp:
            timestamp = (datetime.utcnow() - timedelta(hours=default_hours_ago)).isoformat() + 'Z'
        return timestamp
    
    def set_timestamp(self, key: str = 'last_timestamp', 
                      value: Optional[str] = None) -> None:
        """Set timestamp checkpoint"""
        if value is None:
            value = datetime.utcnow().isoformat() + 'Z'
        self.set(key, value)
    
    def clear(self) -> None:
        """Clear checkpoint state"""
        self._state = {}
        if os.path.exists(self.filepath):
            os.remove(self.filepath)
        logger.info("Cleared checkpoint")


# Usage example
if __name__ == '__main__':
    cp = Checkpoint('/opt/splunk/var/lib/splunk/modinputs', 'test_input')
    
    # Get last timestamp (defaults to 24 hours ago)
    since = cp.get_timestamp()
    print(f"Collecting since: {since}")
    
    # After collection, update checkpoint
    cp.set_timestamp(value='2024-01-15T12:00:00Z')
    cp.set('last_id', 12345)
    cp.save()

Common API Integration Patterns

Pattern 1: Paginated API with Cursor

Cursor-Based Pagination 
def collect_with_cursor(session, checkpoint):
    """Collect using cursor-based pagination"""
    cursor = checkpoint.get('cursor')
    
    while True:
        params = {'limit': 100}
        if cursor:
            params['cursor'] = cursor
        
        response = session.get('/api/events', params=params)
        data = response.json()
        
        for event in data.get('items', []):
            print(json.dumps(event))
        
        cursor = data.get('next_cursor')
        if not cursor:
            break
        
        checkpoint.set('cursor', cursor)
        checkpoint.save()
    
    # Clear cursor on complete collection
    checkpoint.set('cursor', None)
    checkpoint.save()

Pattern 2: Offset Pagination

Offset-Based Pagination 
def collect_with_offset(session, checkpoint):
    """Collect using offset-based pagination"""
    page_size = 100
    offset = 0
    
    while True:
        params = {
            'limit': page_size,
            'offset': offset,
            'sort': 'timestamp:asc'
        }
        
        response = session.get('/api/events', params=params)
        data = response.json()
        
        items = data.get('items', [])
        if not items:
            break
        
        for event in items:
            print(json.dumps(event))
        
        offset += len(items)
        
        # Stop if we got less than a full page
        if len(items) < page_size:
            break

Pattern 3: Time-Range Windowing

Time-Window Collection 
from datetime import datetime, timedelta

def collect_time_windows(session, checkpoint, window_minutes=60):
    """Collect using time-based windows"""
    start_time = datetime.fromisoformat(
        checkpoint.get_timestamp().replace('Z', '+00:00')
    )
    end_time = datetime.utcnow()
    
    current_start = start_time
    
    while current_start < end_time:
        current_end = min(
            current_start + timedelta(minutes=window_minutes),
            end_time
        )
        
        params = {
            'start_time': current_start.isoformat() + 'Z',
            'end_time': current_end.isoformat() + 'Z'
        }
        
        response = session.get('/api/events', params=params)
        
        for event in response.json().get('items', []):
            print(json.dumps(event))
        
        # Update checkpoint after each window
        checkpoint.set_timestamp(value=current_end.isoformat() + 'Z')
        checkpoint.save()
        
        current_start = current_end

Validation Queries

Check Script Execution

SPL - Script Execution Status 
index=_internal sourcetype=splunkd component=ExecProcessor
| rex field=_raw "script\s+(?<script_path>[^\s]+)"
| stats latest(_time) as last_run,
        count as executions,
        values(log_level) as status
BY script_path
| eval time_since = now() - last_run
| eval health = case(
    time_since < 600, "healthy",
    time_since < 1800, "warning",
    1==1, "stale"
)
| table script_path, last_run, executions, status, health

Check Script Errors

SPL - Script Error Detection 
index=_internal sourcetype=splunkd (component=ExecProcessor OR component=ModularInputs)
    (ERROR OR WARN OR "exit code")
| rex field=_raw "script\s+(?<script>[^\s]+)"
| rex field=_raw "exit code\s*=\s*(?<exit_code>\d+)"
| where isnotnull(script)
| stats count BY script, log_level, exit_code
| sort - count

Troubleshooting

Script Not Executing

Symptoms: No data arriving, no script logs

Resolution:

  • Check input is enabled: ./splunk list exec
  • Verify script permissions: chmod +x script.py
  • Check script path in inputs.conf (relative to bin/)
  • Test script manually: ./bin/custom_api_input.py
  • Check for Python errors: shebang line, syntax errors
  • Review logs: 
    index=_internal sourcetype=splunkd ExecProcessor "script"
Script Exits with Error

Symptoms: Exit code non-zero, partial or no data

Resolution:

  • Check stderr output in Splunk logs
  • Run script manually with debug logging
  • Verify API credentials and connectivity
  • Check for rate limiting (HTTP 429)
  • Validate checkpoint file permissions
  • Debug query: 
    index=_internal sourcetype=splunkd "exit code" script
| table _time, message
Duplicate Events

Symptoms: Same events appearing multiple times

Resolution:

  • Verify checkpoint is being saved after each run
  • Check checkpoint file contents and permissions
  • Ensure timestamp/ID used for checkpointing is monotonic
  • Add deduplication in script logic
  • Clear checkpoint and re-collect if needed
Script Hangs / Times Out

Symptoms: Script doesn't complete within interval

Resolution:

  • Add connection/read timeouts to HTTP requests
  • Reduce page size or max pages per run
  • Increase interval if collection time is legitimately long
  • Use time-windowing to limit data per execution
  • Check for API endpoint health issues
Missing Python Dependencies

Symptoms: ImportError, ModuleNotFoundError

Resolution:

  • Install packages to script's lib directory: 
    pip install -t ./bin/lib requests
  • Or use Splunk's Python: /opt/splunk/bin/python3
  • Bundle dependencies with script
  • Use Splunk SDK for built-in functionality

Rollback & Safety

Emergency: Disable Scripted Input

Emergency Procedure 
SCENARIO: Script causing issues (volume spike, API errors, malformed data)

OPTION 1: Disable Input via Splunk Web (Preferred)
──────────────────────────────────────────────────
1. Settings → Data Inputs → Scripts
2. Find problematic script → Actions → Disable

OPTION 2: Disable via Configuration File
────────────────────────────────────────
1. SSH to Heavy Forwarder / Universal Forwarder
2. Edit: $SPLUNK_HOME/etc/apps/[app_name]/local/inputs.conf
3. Add: disabled = 1 to the script stanza
4. Reload: $SPLUNK_HOME/bin/splunk restart

OPTION 3: Revoke API Credentials (If Script Compromised)
────────────────────────────────────────────────────────
If script credentials may be exposed:
1. Revoke/rotate API credentials at source
2. Script will fail with auth errors (safe failure)
3. Update credentials in Splunk after investigation

COMMUNICATION:
- Notify data source owner if API credentials changed
- Notify SOC (data gap occurring)
- Document incident for post-mortem

Checkpoint Recovery Procedure

Reset Script Checkpoint 
SCENARIO: Need to reset checkpoint (missed data or duplicates)

⚠️ WARNING: Resetting checkpoint may cause duplicate data or missed data depending on your script logic

STEP 1: Locate Checkpoint File
──────────────────────────────
# Common locations:
$SPLUNK_HOME/var/lib/splunk/modinputs/[script_name]/
$SPLUNK_HOME/etc/apps/[app_name]/local/checkpoint/

STEP 2: Disable Script Input
────────────────────────────
Disable the input via Splunk Web (see above)

STEP 3: Backup Current Checkpoint
─────────────────────────────────
cp checkpoint_file checkpoint_file.backup.$(date +%Y%m%d)

STEP 4: Modify Checkpoint
─────────────────────────
# Option A: Re-collect from beginning (will cause duplicates)
rm checkpoint_file

# Option B: Re-collect from specific timestamp
# Edit checkpoint file to set desired start time
echo "2024-01-15T00:00:00Z" > checkpoint_file

# Option C: Skip to current time (will miss data)
echo "$(date -u +%Y-%m-%dT%H:%M:%SZ)" > checkpoint_file

STEP 5: Re-enable Script Input
──────────────────────────────
Enable input via Splunk Web

STEP 6: Monitor for Issues
──────────────────────────
index=[target_index] sourcetype=[script_sourcetype] earliest=-1h
| stats count BY _time span=5m
# Verify data flow pattern looks correct

API Credential Rotation Procedure

Zero-Downtime Credential Rotation 
SCENARIO: Scheduled rotation of API credentials used by script

STEP 1: Generate New Credentials
────────────────────────────────
Create new API key/credentials at the source system
(Keep old credentials active)

STEP 2: Update Splunk Credential Store
──────────────────────────────────────
# If using Splunk credential store:
1. Settings → Storage Passwords
2. Edit existing credential OR create new
3. Update username/password

# If using app-specific credential storage:
1. Edit credential file in app's local/ directory
2. Follow app-specific documentation

STEP 3: Restart Script or Reload Inputs
───────────────────────────────────────
$SPLUNK_HOME/bin/splunk restart

STEP 4: Verify Script Using New Credentials
───────────────────────────────────────────
# Check for auth errors
index=_internal sourcetype=splunkd component=ExecProcessor "script_name"
| search ERROR OR auth OR "401" OR "403"
| head 20

# Should show no auth errors

STEP 5: Revoke Old Credentials
──────────────────────────────
After 24 hours of successful operation:
1. Revoke old credentials at source system
2. Document rotation date

SCHEDULE: Set calendar reminder 30 days before credential expiry

Scripted Input Health Monitoring Query

SPL: Monitor Script Execution Health 
`comment("Create scheduled alert to detect scripted input failures")`

index=_internal sourcetype=splunkd component=ExecProcessor earliest=-1h
| stats 
    latest(_time) AS last_run,
    sum(eval(if(like(message, "%exit code%0%"), 0, 1))) AS error_count,
    count AS total_runs
    BY data_input
| eval hours_since = round((now() - last_run)/3600, 1)
| eval status = case(
    error_count > 0, "🔴 ERRORS - Check script logs",
    hours_since > 2, "🟠 STALE - Script not running",
    total_runs = 0, "🟡 NO RUNS - Check configuration",
    true(), "✅ Healthy"
)
| table data_input, status, last_run, total_runs, error_count

`comment("Also monitor the data output")`
index=[target_index] sourcetype=[script_sourcetype] earliest=-1h
| bucket _time span=5m
| stats count BY _time
| where count = 0
| eval alert = "🔴 NO DATA from scripted input"

`comment("Alert when either query returns results")`
